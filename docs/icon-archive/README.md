# Icon archive

Retired icon drafts, kept for reference. The shipping icon is always generated by
`Scripts/make-icon.swift` (`make icon`); nothing here is used by the build.

## v1-light-amber (2026-10-19)

First light-appearance draft: white tile, near-black dots that darken in the beam,
amber beam / leading edge / captured targets / lamp. Replaced by the monochrome
(white / grey / black) light icon.

- `make-icon-v1-light-amber.swift` — full generator for this draft
  (`swift make-icon-v1-light-amber.swift <out.iconset> light`)
- `icon-1024.png`, `icon-256.png`, `icon-64.png`, `icon-32.png` — rendered sizes
- `preview-sheet.png` — light draft on a light desktop, dark icon on a dark desktop
