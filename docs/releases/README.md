# Pharos 版本发布与更新档案 (Release Archives)

本目录用于归档 Pharos 每个正式版本的详细功能清单、问题修复、变更背景与发布日志（Release Notes）。

## 规范说明 (AGENTS.md 约定)

从 **v3.3.0** 起，所有 AI Agent / 开发者在进行新版本研发、功能迭代或版本发布时，**必须**在本目录维护对应的版本文件：

1. **文件命名格式**：`docs/releases/v<版本号>.md`（如 `v3.3.0.md`、`v3.4.0.md`）。
2. **内容要求**：
   - **版本元数据**：版本号、发布日期、代号/主题、作者。
   - **核心改动清单**：按功能模块（主导航、系统硬件、散热与风扇、清理与工具等）细化记录背景、实现方案与 UI 视觉改进。
   - **问题修复（Bug Fixes）**：记录修复的具体 Bug、根本原因与解决方案。
   - **双语 Release Notes（中英双语）**：用于直接复制至 GitHub Releases 正文与更新提示。
3. **发版同步**：在执行正式版本发布时，将该版本的核心摘要同步至根目录的 `CHANGELOG.md`。
