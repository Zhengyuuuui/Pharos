## 一、核心功能与架构升级

### 1. 主侧边栏解耦重构与根治文字截断
- **架构解耦（独立「电池与充电」与「风扇与温度」）**：
  - 将原单行揉合的 `BatteryAndThermalSidebarRow` 解耦拆分为两个独立顶层导航项：
    - `电池与充电`（图标 `battery.100.bolt`）：专精电源管理、80% 硬件限充（Tahoe 原生风格）、放电管理与 MagSafe 指示灯同步。右侧仅保留纯净电池状态（如 `⚡️ 85%`）。
    - `风扇与温度`（图标 `fanblades`）：专精散热与算力管理、拟真双风扇仪表、SMC 自定义温控曲线。右侧仅保留峰值芯片温度（如 `52°C`，高温带火焰告警）。
  - **扁平化页面层级**：移除中间态的外层分段切换控制条（`[电池与充电] | [风扇与温度]`），用户在左侧点选哪个硬件，右侧即刻直达专精控制面板，减少操作层级。
- **根治 236pt 侧边栏浮岛下的文字挤压截断 Bug**：
  - 此前因在单行内塞入“5汉字标题 + 充电图标 + 电池百分比 + 分隔点 + 芯片温度”导致标题在默认宽度下被强制截断为 `电源与...`；
  - 拆分后两行各自独立拥有超过 100pt 的水平留白，标题文字永久舒展，在任意窗口尺寸下绝不出现截断。

### 2. 闭环集成「CPU 异常占用与发热排查」
- **发热与因果闭环**：
  - 用户电脑飙升至 90°C+ 高温时，核心痛点是“谁在把 CPU 烧烫、如何一站式降温”。
  - 将「风扇与温度」页面原本抽象静态的发热描述（“编译任务”、“媒体转码”）重构为实时的**高负荷与失控孤儿进程排查看板**。
- **实时识别失控与孤儿进程（纯逻辑放 `PharosCore`）**：
  - 重点侦测持续占用高 CPU（> 70%）或脱离父终端的孤儿开发脚本（`ppid == 1` 的 Python、Node、ffmpeg、死循环构建进程等）；
  - 详尽列出进程 PID、实时 CPU 占比、已持续运行时长、完整命令行参数及执行工作目录；
  - 遵循 `AGENTS.md` 安全守则，提供安全的「结束进程」交互（优先优雅 SIGTERM，仍存活时提供强制 SIGKILL）。
- **杜绝跨页指标噪音**：
  - 温度与 CPU 异常发热严格收拢于「风扇与温度」页内，绝不在系统内存、磁盘或清理页面重复复制温度数据，保持界面克制纯净。

### 3. 菜单栏微缩 SF Symbols 图标状态栏合成渲染器
- **原生微缩 SF Symbols 图标化**：
  - 新增 `MenuBarDisplayStyle`，全面取代原先生硬的 `P`、`PRJ`、`MEM`、`DISK` 等大写英文字母缩写；
  - 引入 Retina 像素级单张画布合成渲染器 `MenuBarCompositeRenderer.render(...)`：左侧为 18×18 动态进度圆环，右侧紧凑绘制微缩 SF Symbol（如 `network`、`thermometer.medium`、`memorychip`）与等宽数值（`:22`、`70°C`、`60%`）。
- **「自定义」菜单栏定制器宽屏重构**：
  - 指标卡片网格从拥挤的 3 列改为宽敞的 2 列（176pt 宽），彻底解决数值换行断开问题（数值与单位 `°C` / `%` 永久同行）；
  - 独立成行的快捷预设胶囊按钮，防止小窗口宽度下的按钮文字截断；
  - 新增顶部「当前启用顺序条（Active Order Strip）」，支持通过微调箭头直观调整多指标显示顺序。

### 4. 风扇底层守护驱动 v2 协议升级与防掉线加固
- **协议升级至 v2 与驱动版本在线感知**：
  - 底层 privileged helper（`pharos-fand`）与 `FanProtocol` 升级为 `version = 2`；
  - `FanStore` 自动比对底层已安装驱动版本，驱动版本滞后时在卡片顶部主动展示 **「核心驱动守护进程有新版本」** 提示横幅，支持一键调起 macOS 原生密码框升级底层驱动，彻底杜绝指令解析失败的 `bad request` 报错。
- **心跳守护加入 RunLoop `.common` 模式**：
  - 将心跳定时器注册到主线程 RunLoop 的 `.common` 模式，即使在窗口中拖动滑块、滚动列表或操作菜单栏，心跳也绝不挂起中断；
  - 活跃控制心跳间隔由 5.0s 优化为 3.0s，提供 5 倍于 15s 超时熔断的安全冗余。
- **休眠唤醒（Sleep/Wake）0 延迟恢复**：
  - 监听 `NSWorkspace.didWakeNotification`，系统合盖休眠唤醒后 0 延迟自动重新下发手动设定转速与解锁指令，杜绝休眠后掉回系统控制。
- **滑动条松手即生效**：
  - 为固定转速滑块增加 `onEditingChanged`，用户拖拽释放即刻下发设定转速，无需额外寻找点击「应用」按钮。

## 二、问题修复与稳定性改进 (Bug Fixes)

1. **修复「智能曲线」报错 `bad request` 的问题**：
   - 根本原因：系统已安装的 `/Library/PrivilegedHelperTools/local.pharos.fand` 仍为早期版本，协议未做版本自检，旧驱动无法识别 `"curve"` 模式字符串直接报错；
   - 修复：升级协议至 v2，建立版本号探测机制与驱动一键更新路径。
2. **修复固定转速有时候会自动掉回系统默认控制的问题**：
   - 根本原因：原 `FanStore` 心跳计时器运行于 `.default` RunLoop 模式，UI 拖拽交互期间心跳暂停超过 15 秒触发守护进程超时保护；休眠唤醒后 SMC 寄存器重置未重新下发；
   - 修复：心跳切换为 `.common` 模式，间隔缩短至 3.0s，增加休眠唤醒自动恢复与 SMC 写入微重试机制。
3. **修复主侧边栏「电池与散热」标题文字截断 Bug**：
   - 拆解为「电池与充电」和「风扇与温度」两行，解决双数值挤占空间的排版冲突。

## 三、双语 Release Notes

### English
- **Decoupled Sidebar Navigation & Text Truncation Fix**:
  - Split the overloaded `Power & Thermals` row into two dedicated, first-class sidebar navigation items: `Battery & Charging` and `Fans & Temperature`.
  - Permanently eliminates the label truncation bug in the 236pt sidebar island by dedicating clean whitespace to individual battery/thermal status badges.
- **CPU Heat & Runaway Process Diagnostics**:
  - Integrated live CPU process heat diagnostics directly below the fan control cockpit in `Fans & Temperature`.
  - Automatically surfaces sustained high-CPU (>70%) and orphaned background tasks (e.g., forgotten Python/Node/ffmpeg scripts with `ppid == 1`), displaying runtime duration, PID, and full command arguments with safe one-click termination.
- **Micro SF Symbol Status Bar Composite Renderer**:
  - Replaced bulky uppercase letter labels (`PRJ`, `MEM`, `DISK`) with native micro SF Symbols paired with monospaced metrics.
  - Rendered via a single high-DPI composite canvas ensuring pixel-perfect alignment in the macOS status bar and live preview.
- **Fan Control Daemon v2 & Rock-Solid Heartbeats**:
  - Bumped `pharos-fand` communication protocol to v2 with automatic version detection and one-click in-app driver upgrade banners.
  - Heartbeat timer now runs in RunLoop `.common` mode, preventing fixed fan speed resets while dragging UI controls or moving windows.
  - Added sleep/wake observation (`NSWorkspace.didWakeNotification`) to automatically re-apply manual fan speeds upon system resume.
