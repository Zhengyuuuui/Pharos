## 核心设计准则 (Feedback Implementation)

1. **单视窗展示与杜绝重复交通灯 (Single Window & Single Traffic Lights)**：
   - 彻底摒弃多窗口层叠杂乱的展示形态，全片中央**同一时刻仅呈现一个核心视窗**。
   - **严禁双重交通灯 (No Double Traffic Lights)**：因为真机录屏素材（如 `01-dashboard.mp4`、`03-cleanup.mp4`）内部**本身已经完整录制了 macOS 原生红黄绿交通灯与窗口标题栏**，Remotion 视窗外壳**严禁再在视频外部套一层假的交通灯顶栏**！外层只需提供平滑圆角（`borderRadius: 20px`）、`overflow: hidden` 与多层高奢弥散投影，展现单层真实的原生交通灯。
   - 窗口切换采用极具物理连贯性的转场动效（上升穿透、侧向滑推、向心塌缩），丝滑承接。
2. **定制背景音乐与零碰撞杂音 (Custom BGM & Zero Crash)**：
   - **指定背景音乐**：采用用户指定的 `2007(2)` - Lvcien（124 BPM 氛围电子，已部署至 `public/audio/bgm.mp3`）。
   - BGM 贯穿全片（f0–f1305）：开头 1.5s（f0–45）平滑淡入，结尾 2.0s（f1245–1305）平滑淡出。
   - **严禁**出现任何“咚”一声的沉重碰撞音效（坚决移除 `fs-812736.mp3`）。
   - 仅保留极轻盈的声效：声呐微鸣、空气微风、平滑气泡与终端打字声。
3. **真实高保真录屏 (Real Retina Screen Captures)**：
   - 直接读取并嵌入真机录制的 MP4 视频，保留原生 AppKit / SwiftUI 的字体抗锯齿、毛玻璃光晕与真实交互反馈。
